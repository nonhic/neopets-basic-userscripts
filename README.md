# neopets-basic-userscripts
Basic userscripts to be used in tampermonkey (tested on Chrome) on neopets dot com to make little things easier. :)

## training-quick-course.user.js
This script creates shortcuts to start training courses at all three schools for each of your pets, with updated code to support the recent security upgrades to the Ninja Training page which makes use of GM.set/getValue to store your chosen pet/course and sets it up accordingly on the course select page.  Should be compatible with or without Premium.
